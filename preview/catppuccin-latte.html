把 16 套主题各出一张预览图，深色主题的代码块要好看。

已按 --dsw-alias-* 语义层完成映射，规则：

  • 背景四层与侧栏取自调色板原色，层级不乱；
  • 状态色 成功 / 警告 / 错误 沿用主题官方色。
javascript复制
// 调色板 → DSH 语义 token 覆盖表
const themes = palettes.map((p) => ({
  id: p.id,                       // 例：'tokyo-night'
  colorScheme: 'dark',
  tokens: tokensFor(p),             // --dsw-alias-* 全集
  swatches: 4,
}));
export default themes;

配色数据源：src/palettes.mjs · 映射器：src/tokens.mjs
